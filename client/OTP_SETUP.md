# Настройка OTP аутентификации через SMS.RU и Email

## Обзор

Система аутентификации полностью переработана на **OTP (One-Time Password)** - одноразовые коды для входа. Пароли больше не используются.

### Поддерживаемые методы входа:
- 📱 **Телефон** - SMS через SMS.RU API (российские номера +7XXXXXXXXXX)
- 📧 **Email** - SMTP отправка через Nodemailer

### Ключевые особенности:
- ✅ Нет паролей - только OTP коды
- ✅ Refresh токен действует 60 дней (2 месяца)
- ✅ OTP код истекает через 5 минут
- ✅ Защита от спама: cooldown 60 секунд между отправками
- ✅ Защита от брутфорса: максимум 5 попыток ввода кода
- ✅ Rate limiting на эндпоинты
- ✅ Двухшаговый процесс входа/регистрации

## 1. Получение SMS.RU API ключа

### Шаг 1: Регистрация на SMS.RU

1. Перейдите на [sms.ru](https://sms.ru/)
2. Нажмите "Регистрация" или "Личный кабинет"
3. Заполните форму регистрации (email, пароль)
4. Подтвердите email

### Шаг 2: Пополнение баланса

1. Войдите в личный кабинет SMS.RU
2. Перейдите в раздел "Финансы" → "Пополнить счет"
3. Выберите удобный способ оплаты (карта, электронные деньги и т.д.)
4. Минимальная сумма пополнения: 100 рублей
5. **Стоимость:** ~2-3 рубля за SMS в зависимости от оператора

### Шаг 3: Получение API ключа

1. В личном кабинете перейдите в раздел **"Настройки"** → **"API"**
2. Найдите поле **"API ID"** - это ваш ключ
3. Скопируйте значение API ID (например: `1234567-ABCD-4E5F-G6H7-89IJKLMNOP01`)
4. **Важно:** Сохраните этот ключ в безопасном месте

### Шаг 4: Настройка отправителя (опционально)

1. Перейдите в **"Настройки"** → **"Имена отправителей"**
2. Добавьте имя отправителя (например: "IBRShop")
3. Дождитесь модерации (обычно 1-2 дня)
4. После одобрения SMS будут приходить с вашим именем

## 2. Настройка Backend (Server)

### 2.1. Установка зависимостей

```bash
cd server
npm install
```

Зависимости уже добавлены в `package.json`:
- `axios` - для HTTP запросов к SMS.RU API
- `express-rate-limit` - защита от спама

### 2.2. Настройка переменных окружения

Создайте или обновите файл `server/.env`:

```env
# MongoDB
MONGODB_URI=mongodb://localhost:27017/ibr-shop

# JWT Secrets
SECRET_KEY_ACCESS_TOKEN=your_access_token_secret_here
SECRET_KEY_REFRESH_TOKEN=your_refresh_token_secret_here
JSON_WEB_TOKEN_SECRET_KEY=your_jwt_secret_here

# Email (SMTP) - уже настроено
EMAIL_HOST=smtp.mail.ru
EMAIL_PORT=465
EMAIL_USER=your-email@mail.ru
EMAIL_PASSWORD=your-email-password

# SMS.RU API (НОВОЕ - добавьте это!)
SMS_RU_API_ID=ваш_api_id_от_sms_ru

# OTP настройки (опционально)
OTP_EXPIRY_MINUTES=5
OTP_MAX_ATTEMPTS=5
OTP_RESEND_COOLDOWN_SECONDS=60

# Сервер
PORT=8080
NODE_ENV=development
```

**⚠️ Важно:**
- Замените `SMS_RU_API_ID` на ваш реальный API ID от SMS.RU
- В production установите `NODE_ENV=production`

### 2.3. Запуск сервера

```bash
# Development режим
npm run dev

# Production режим
npm start
```

### 2.4. Проверка работы

Сервер должен запуститься на `http://localhost:8080`. Проверьте логи:

```
Server is running 8080
```

## 5. API Эндпоинты

### 5.1. Отправка OTP кода

**POST** `/api/user/send-otp`

**Body:**
```json
{
  "contact": "+79991234567",
  "method": "phone",
  "name": "Иван" // опционально, для регистрации
}
```

**Response:**
```json
{
  "success": true,
  "error": false,
  "message": "Код подтверждения отправлен на телефон"
}
```

### 5.2. Верификация OTP кода

**POST** `/api/user/verify-otp`

**Body:**
```json
{
  "contact": "+79991234567",
  "otp": "123456",
  "method": "phone"
}
```

**Response:**
```json
{
  "success": true,
  "error": false,
  "message": "Вход выполнен успешно",
  "data": {
    "accesstoken": "...",
    "refreshToken": "..."
  },
  "user": {
    "_id": "...",
    "name": "Иван",
    "mobile": "+79991234567",
    "email": null,
    "role": "USER"
  }
}
```

### 5.3. Повторная отправка кода

**POST** `/api/user/resend-otp`

**Body:** (такое же как `/send-otp`)
```json
{
  "contact": "+79991234567",
  "method": "phone"
}
```

## 6. Безопасность

### 6.1. Rate Limiting

Автоматическая защита от спама:

| Эндпоинт      | Лимит      | Период   |
| ------------- | ---------- | -------- |
| `/send-otp`   | 5 запросов | 15 минут |
| `/verify-otp` | 10 попыток | 5 минут  |
| `/resend-otp` | 3 запроса  | 15 минут |

### 6.2. OTP Защита

- **Cooldown:** 60 секунд между отправками кода одному пользователю
- **Попытки:** Максимум 5 попыток ввода кода
- **Истечение:** OTP код действителен 5 минут
- **Удаление:** После 5 неудачных попыток код сбрасывается

### 6.3. Валидация

- **Телефон:** Только российские номера `+7XXXXXXXXXX`
- **Email:** Стандартная валидация email
- **OTP:** Только 6 цифр `^\d{6}$`

## 7. Возможные ошибки и решения

### Ошибка: "SMS.RU API не настроен"

**Причина:** Не указан `SMS_RU_API_ID` в `.env` файле

**Решение:**
1. Проверьте файл `server/.env`
2. Добавьте строку: `SMS_RU_API_ID=ваш_api_id`
3. Перезапустите сервер

### Ошибка: "Неправильный api_id"

**Причина:** Неверный API ключ от SMS.RU

**Решение:**
1. Проверьте API ID в личном кабинете SMS.RU
2. Убедитесь, что скопировали полный ключ
3. Обновите `.env` файл

### Ошибка: "Не хватает средств на лицевом счету"

**Причина:** Нулевой или отрицательный баланс на SMS.RU

**Решение:**
1. Войдите в личный кабинет SMS.RU
2. Пополните баланс (минимум 100 рублей)
3. Повторите отправку SMS

### Ошибка: "Слишком много попыток отправки кода"

**Причина:** Превышен rate limit

**Решение:**
1. Подождите 15 минут
2. Попробуйте снова
3. В development можно временно увеличить лимиты в `server/middlewares/rateLimiter.js`

### Ошибка: "Неверный формат номера телефона"

**Причина:** Номер не соответствует формату +7XXXXXXXXXX

**Решение:**
1. Проверьте формат: +7 (999) 123-45-67
2. Убедитесь, что это российский номер
3. Номер должен начинаться с +7 или 8

### 8.2. Проверка баланса SMS.RU

Добавьте эндпоинт для проверки баланса (опционально):

```javascript
// server/controllers/user.controller.js
export async function checkSmsBalance(request, response) {
  try {
    const balance = await smsService.getBalance();
    return response.json({
      success: true,
      balance: balance,
      message: `Баланс: ${balance} руб.`
    });
  } catch (error) {
    return response.status(500).json({
      error: true,
      message: error.message
    });
  }
}
```
