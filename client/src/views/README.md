# src/views/ — компоненты страниц (слой FSD)

Здесь лежат композиции страниц, которые подключаются из `src/app/**/page.tsx` (App Router).

## Структура

- Экспорт — именованные React-компоненты.
- Импорт в маршрутах: `import { HomePage } from '@/views/home/HomePage'`.

## Почему не `src/pages/`?

Next.js резервирует `pages/` и `src/pages/` под **Pages Router**. При наличии `src/app/` включается гибридный режим: всё в `src/pages/` трактуется как маршруты и должно иметь `default export` страницы. Слой FSD с тем же именем ломает сборку.

Папка `views` (или другое имя вне зарезервированных путей) устраняет конфликт.
